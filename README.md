# Donaciones LaCardio — versión definitiva

Landing page institucional de donaciones, pensada para GitHub Pages y especialmente para celular.

## Incluye
- Diseño azul, rojo y blanco inspirado en la identidad visual.
- Hero de alto impacto con la campaña original sin modificar.
- Botones de donación animados y enlaces ePayco.
- Opción "Otro valor" con formulario y protección anti-spam.
- Avisos visibles de seguridad, privacidad y Habeas Data.
- Correo de protección de datos: habeasdata@fundacioncardioinfantil.com.co
- Pie de página con derechos reservados.
- Google Analytics 4: G-30QGR4ZMD5.
- Animaciones con respeto a `prefers-reduced-motion`.

## Publicación
Sube/reemplaza `index.html`, `style.css`, `script.js` y la carpeta `assets` en el repositorio de GitHub Pages.
