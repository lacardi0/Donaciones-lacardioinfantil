IMPORTANTE SOBRE ePayco:
Los botones de $200.000, $500.000, $1.000.000, $2.000.000 y $4.000.000 enlazan a los checkout que fueron proporcionados. Si al abrir uno aparece una pantalla de ePayco con otros valores (por ejemplo $30.000, $50.000 y $120.000), esos valores pertenecen a la configuración de ese checkout en ePayco y deben corregirse dentro de ePayco; no los controla este sitio de GitHub Pages.
